# Gestion de clientes

Aplicacion realizada en PHP para gestionar clientes.

## Ejecucion

Copiar la carpeta en XAMPP/htdocs y abrir:

http://localhost/gestion-clientes/

## Funciones

- Ver listado de clientes.
- Añadir un cliente.
- Eliminar un cliente.

Los clientes se guardan en un fichero JSON.

Se utiliza PHP y Bootstrap para la interfaz.
