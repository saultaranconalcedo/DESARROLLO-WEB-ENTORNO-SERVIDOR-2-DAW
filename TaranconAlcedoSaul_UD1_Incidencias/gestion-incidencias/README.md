# Gestion de incidencias

Aplicacion realizada en PHP para gestionar incidencias.

## Ejecucion

Copiar la carpeta en XAMPP/htdocs y abrir:

http://localhost/gestion-incidencias/

## Funciones

- Ver incidencias.
- Crear incidencias.
- Consultar y cambiar estado.
- Eliminar incidencias.

Los datos se guardan temporalmente mediante sesiones PHP.

Se utilizan GET, POST, PUT y DELETE.
