# Ejercicio 4: Testing de gestión de incidencias

Esta carpeta documenta las pruebas del ejercicio 3 y contiene una copia funcional de la aplicación en `aplicacion/`.

- `pruebas/caja-negra.md`: entradas y resultados observables de los escenarios T01–T05.
- `pruebas/caja-blanca.md`: caminos principales de las funciones de autenticación, permisos y filtrado.
- `pruebas/pruebas-funcionales.md`: comprobaciones manuales de formularios, roles y cookies.
- `errores-corregidos.md`: dos errores detectados durante las pruebas, sus causas, correcciones y comprobaciones.

Para repetirlas, abre `aplicacion/index.php` desde el servidor local (por ejemplo, XAMPP) y utiliza las cuentas del README de la aplicación.
